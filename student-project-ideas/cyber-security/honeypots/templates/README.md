# Templates

Two templates for working through the [Honeypots project](../README.md):

- **[DAILY_LOG_TEMPLATE.md](DAILY_LOG_TEMPLATE.md)** — copy this at the start of the week and fill in one section per day. It's your running journal: what you did, what broke, what you saw. Low-effort, write-as-you-go.
- **[WRITEUP_TEMPLATE.md](WRITEUP_TEMPLATE.md)** — fill this in at the end, using your daily log as raw material. This is the polished version meant to be read by someone else (instructor, portfolio, personal statement).

## How to use

1. Copy both files into your own project folder (don't edit these directly, so the templates stay clean for the next student):
   ```bash
   cp templates/DAILY_LOG_TEMPLATE.md my-project/DAILY_LOG.md
   cp templates/WRITEUP_TEMPLATE.md my-project/WRITEUP.md
   ```
2. Update `DAILY_LOG.md` each day of the week.
3. At the end, write `WRITEUP.md` using the daily log as your source material — the write-up should be shorter and more polished than the log, not a copy of it.
4. Keep both in your project's git history — the daily log is good evidence of process, the write-up is the deliverable.
